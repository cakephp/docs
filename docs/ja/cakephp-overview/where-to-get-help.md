# 情報の探し方

CakePHP 2 は CakePHP プロジェクトではサポートが終了 (EOL) しています。
以下には、Piece of Cake 2 フォークのための情報源と、CakePHP 全般の情報源があります。

## GitHub の Piece of Cake 2

<https://github.com/pieceofcake2>

CakePHP 2 のフォーク、アプリケーションスケルトン、保守しているプラグインは GitHub で開発しています。
バグや PHP 8 での互換性の問題を見つけたら、該当するリポジトリに Issue を作成してください。
たとえばフレームワークは [pieceofcake2/cakephp](https://github.com/pieceofcake2/cakephp/issues)、
アプリケーションスケルトンは [pieceofcake2/app](https://github.com/pieceofcake2/app/issues)、
このドキュメントは [pieceofcake2/docs](https://github.com/pieceofcake2/docs/issues) です。
PHP のバージョン、エラーメッセージ、可能であれば問題を再現できる最小限のコードを添えてください。

## 公式 CakePHP ウェブサイト

<https://cakephp.org>

公式 CakePHP ウェブサイトは、いつでも見に行く価値のある素敵な場所です。
CakePHP の最新バージョンや開発ツール、コミュニティの情報へのリンクがあります。

## Cookbook

<https://pieceofcake2.github.io/docs/ja/>

このマニュアルは、疑問の解決のための最初の場所になるはずです。
他のさまざまなオープンソースプロジェクトと同じように、常に新しい仲間が入ってきます。
疑問の答えをこの場所で探してみてください。
時間がかかるかもしれませんが、貴重な知識を多く身につけることができるでしょう。
また、どんなサポートがあるのかについても見えてくるはずです。
CakePHP の最新バージョンのクックブックは <https://book.cakephp.org> にあります。

## Bakery

<https://bakery.cakephp.org>

CakePHP の Bakery は、CakePHP に関する情報中継所 (*clearing house*) です。
ニュース、チュートリアル、事例研究、コード例などについて情報が得られます。
古い記事の多くは CakePHP 2 向けに書かれています。

## API

<https://api.cakephp.org/2.x/>

直接的な答えがコア開発者から直接得られるので、
CakePHP API (*Application Programming Interface*) は、
フレームワークの内部動作に関する詳細に関する、もっとも総合的なドキュメントです。
この文書は、直接的なコードリファレンスですので、技術的に十分な理解を持っている
ことを前提としています。
API リファレンスはオリジナルの CakePHP 2.x のものです。フォークでの変更点は
[アップグレードガイド](/ja/appendices/migrating-from-cakephp-2-10) を参照してください。

## テストケース

API で提供される情報が十分ではないと感じる場合、CakePHP で提供されるテストケースの
コードをチェックしてください。
関数の実践的な例やクラスのメンバーの使用法として使用できます。
テストケースは [pieceofcake2/cakephp](https://github.com/pieceofcake2/cakephp/tree/2.x/tests/TestCase)
リポジトリの `tests/TestCase` ディレクトリにあります。

## 公式 CakePHP フォーラム

[CakePHP 公式フォーラム](https://discourse.cakephp.org)

公式フォーラムは、助けを求めたり、アイディアを提案したり、CakePHP について
語り合う場所です。素早く答えや助けを得るために最適です。
サインアップして、CakePHP ファミリーに参加しましょう。

## Stackoverflow

[https://stackoverflow.com/](https://stackoverflow.com/questions/tagged/cakephp/)

Stack Overflow の既存ユーザーが質問を見つけやすくするために、質問の際には
`cakephp` タグと利用中のバージョンを明記して下さい。
