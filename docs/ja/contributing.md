# 貢献

CakePHP 2 の Piece of Cake 2 フォークに貢献する方法は数多くあります。
本家の CakePHP 2.x ブランチはサポートが終了しており、CakePHP コアチームは 2.x の
Issue や Pull Request を受け付けていません。そのため、貢献は GitHub の
[Piece of Cake 2](https://github.com/pieceofcake2) Organization のリポジトリに送ってください。

- フレームワークは [pieceofcake2/cakephp](https://github.com/pieceofcake2/cakephp)
- アプリケーションスケルトンは [pieceofcake2/app](https://github.com/pieceofcake2/app)、
  Bake とメンテナンスしているプラグインはそれぞれの `pieceofcake2/*` リポジトリ
  ([メンテナンスされているプラグイン](/ja/plugins/maintained-plugins) を参照)
- このドキュメントは [pieceofcake2/docs](https://github.com/pieceofcake2/docs)

Issue の報告、開発環境の準備、テストの実行、Pull Request の送り方は、これらすべての
リポジトリに適用される Organization の
[コントリビューションガイド (CONTRIBUTING.md、英語)](https://github.com/pieceofcake2/.github/blob/master/CONTRIBUTING.md) で説明しています。
この章のページでは概要を説明し、その該当するセクションにリンクしています。
