::: pieceofcake2
CakePHP 2.x has reached End of Life upstream, so the CakePHP core team no longer
accepts issues or pull requests for it. Contributions to the pieceofcake2 fork
go to the repositories of the [Piece of Cake 2](https://github.com/pieceofcake2)
organization: [pieceofcake2/cakephp](https://github.com/pieceofcake2/cakephp)
for the framework, the corresponding `pieceofcake2/*` repository for the
application skeleton, Bake and maintained plugins (see
[Plugins](/pieceofcake2/plugins)), and
[pieceofcake2/docs](https://github.com/pieceofcake2/docs) for this book.
:::
