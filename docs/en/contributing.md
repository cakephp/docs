# Contributing

There are a number of ways you can contribute to the Piece of Cake 2 fork of
CakePHP 2. The original CakePHP 2.x branch has reached its end of life, and the
CakePHP core team no longer accepts issues or pull requests for it, so
contributions go to the repositories of the
[Piece of Cake 2](https://github.com/pieceofcake2) organization on GitHub:

- [pieceofcake2/cakephp](https://github.com/pieceofcake2/cakephp) for the
  framework.
- [pieceofcake2/app](https://github.com/pieceofcake2/app) for the application
  skeleton, and the other `pieceofcake2/*` repositories for Bake and the
  maintained plugins (see [Maintained Plugins](/plugins/maintained-plugins)).
- [pieceofcake2/docs](https://github.com/pieceofcake2/docs) for this book.
