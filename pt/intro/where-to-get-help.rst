Onde Obter Ajuda
################

O Site Oficial do CakePHP
==========================

`https://cakephp.org <https://cakephp.org>`_

O site oficial do CakePHP é sempre um ótimo lugar para visitar. Ele apresenta links
para ferramentas de desenvolvedor frequentemente usadas, screencasts, oportunidades de doação e downloads.

O Cookbook
==========

`https://book.cakephp.org <https://book.cakephp.org>`_

Este manual provavelmente deve ser o primeiro lugar para onde você vai para obter respostas. Assim como
muitos outros projetos de código aberto, recebemos novas pessoas regularmente. Tente o seu melhor para
responder suas perguntas por conta própria primeiro. As respostas podem vir mais devagar, mas permanecerão
por mais tempo – e você também estará aliviando nossa carga de suporte. Tanto o manual
quanto a API têm um componente online.

The Bakery
==========

`https://bakery.cakephp.org <https://bakery.cakephp.org>`_

A Bakery do CakePHP é um centro de informações para todas as coisas sobre CakePHP. Confira
para tutoriais, estudos de caso e exemplos de código. Uma vez que você esteja familiarizado
com o CakePHP, faça login e compartilhe seu conhecimento com a comunidade e ganhe
fama e fortuna instantâneas.

A API
=====

`https://api.cakephp.org/ <https://api.cakephp.org/>`_

Direto ao ponto e direto dos desenvolvedores do núcleo, a API do CakePHP
(Application Programming Interface) é a documentação mais abrangente
sobre todos os detalhes minuciosos do funcionamento interno do
framework. É uma referência de código direta, então traga seu chapéu de hélice.

Os Casos de Teste
=================

Se você sentir que a informação fornecida na API não é suficiente, confira
o código dos casos de teste fornecidos com o CakePHP. Eles podem servir como
exemplos práticos para uso de função e membro de dados para uma classe. ::

    tests/TestCase/

Slack
=====

`Canal de Suporte Slack do CakePHP <https://cakesf.slack.com/messages/german/>`_

Se você estiver preso, nos dê um alô no canal de suporte Slack do CakePHP.
Adoraríamos ouvir de você, seja se você precisa de ajuda, quer
encontrar usuários em sua área, ou gostaria de doar seu carro esportivo novinho em folha.

Fórum Oficial do CakePHP
=========================
`Fórum Oficial do CakePHP <https://discourse.cakephp.org>`_

Nosso fórum oficial onde você pode pedir ajuda, sugerir ideias e conversar
sobre CakePHP. É um lugar perfeito para encontrar rapidamente respostas e ajudar outras pessoas.
Junte-se à família CakePHP inscrevendo-se.

Stackoverflow
=============

`https://stackoverflow.com/ <https://stackoverflow.com/questions/tagged/cakephp/>`_

Marque suas perguntas com ``cakephp`` e a versão específica que você está usando para
permitir que os usuários existentes do stackoverflow encontrem suas perguntas.
